# Smart Code Optimizer (스마트 코드 최적화 도구)

> **OS 제약 없이 브라우저에서 바로 실행되는 웹 기반 코드 최적화/정렬 도구**

별도의 설치나 로컬 서버 설정(`Live Server`, `Node.js` 등) 없이 `index.html` 파일을 더블클릭해 즉시 실행할 수 있는 웹 애플리케이션입니다.

---

## 주요 기능

* **언어 선택 및 자동 감지:** HTML, CSS, JavaScript, Python, C, C++, Go를 선택할 수 있으며, 입력된 코드의 문법을 바탕으로 언어를 자동 감지합니다.
* **코드 압축 (Minify):** 지원되는 언어의 불필요한 공백과 주석 등을 정리해 파일 용량을 줄입니다.
* **코드 정렬 (Pretty Print):** 지원되는 언어의 들여쓰기를 정리해 가독성을 높입니다.
* **실시간 용량 계산:** 바이트(Byte) 단위 용량과 압축 절감률(%)을 계산합니다.
* **클립보드 복사:** 결과물을 원클릭으로 복사합니다.

### Go와 C를 지원하는데 GitHub 언어 비율은 왜 HTML 100%인가요?

이 도구는 Go와 C 코드를 입력해 처리할 수 있지만, 그 기능을 구현한 소스 파일은 HTML 파일(`code.html`) 하나입니다. HTML 파일 안에 언어 선택 메뉴와 Go·C 처리 로직이 포함되어 있습니다.

GitHub의 저장소 언어 비율은 도구가 **어떤 언어를 처리할 수 있는지**가 아니라, 저장소에 실제로 들어 있는 소스 파일의 언어 구성을 기준으로 계산합니다. 따라서 Go 또는 C 소스 파일이 따로 없는 현재 저장소는 HTML 100%로 표시됩니다. 이는 Go와 C를 지원하지 않는다는 뜻이 아닙니다.

## 기술 구조 비교

| 구분 | 일반적인 웹 앱 방식 | 본 프로젝트 방식 |
|---|---|---|
| **실행 방식** | 로컬 서버 필요 (`http://`) | 파일 직접 실행 (`file://`) |
| **CORS 보안** | ES6 Module 제약으로 에러 발생 가능 | 단일/전역 스크립트화로 CORS 에러 0개 |
| **의존성** | npm, Webpack 등 빌드 도구 필요 | Pure HTML5 / CSS3 / Vanilla JS |
| **호환성** | 일부 환경 제약 | Windows, macOS, Linux, 모바일 전체 지원 |

## 사용 방법

**1. 로컬 환경에서 바로 사용하기**
1. 이 리포지토리를 다운로드(Zip)하거나 클론합니다.
2. `index.html` 파일을 더블클릭해 브라우저에서 실행합니다.

**2. GitHub Pages 웹 서비스로 활용하기**
* 리포지토리의 `Settings` > `Pages` 메뉴에서 `main` 브랜치를 지정하면 웹 서비스로 배포할 수 있습니다.
