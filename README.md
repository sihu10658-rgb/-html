# 스마트 코드 최적화 도구

브라우저에서 코드를 입력하고 언어를 선택하거나 자동 감지할 수 있는 정적 웹 앱입니다.

## 현재 지원 범위

- **정렬:** Prettier 파서 기반으로 HTML, CSS, JavaScript를 정렬합니다.
- **압축:** Terser로 JavaScript를 압축하고, HTML과 CSS는 브라우저 안에서 문자열·토큰을 보존하는 경량 압축 로직으로 공백과 주석을 줄입니다. Python, C, C++, Go 압축/정렬은 지원하지 않습니다.
- **잠재 이슈 안내:** 입력 중 JavaScript와 HTML의 일부 위험 패턴을 휴리스틱으로 표시합니다. 이는 정적 분석기나 보안 검토를 대체하지 않습니다.
- 자동 언어 감지는 간단한 패턴에 기반하므로 모호하거나 여러 언어가 섞인 코드는 언어를 직접 선택하세요.

> **주의:** 압축/정렬 결과를 원본과 비교하고, 중요한 코드는 해당 언어의 문법 검사와 테스트를 거쳐 사용하세요. 이 앱은 코드를 실행하거나 안전성을 보장하지 않습니다.

## 파일 구성 및 실행

- `code.html` — 앱 진입 파일
- `styles.css` — 화면 스타일
- `script.js` — 언어 감지, 변환, 간단한 진단

파일 세 개를 같은 폴더에 두고 `code.html`을 엽니다. Prettier와 Terser는 고정 버전 CDN으로 로드하므로 JavaScript 정렬/압축에는 인터넷 연결이 필요합니다. HTML/CSS 압축 로직은 앱에 포함되어 있습니다.
