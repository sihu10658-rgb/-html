# 스마트 코드 최적화 도구

브라우저에서 코드를 입력하고 언어를 선택하거나 자동 감지할 수 있는 정적 웹 앱입니다.

> **안전 안내:** 코드가 손상되는 일을 막기 위해 현재 최적화와 정렬 버튼은 입력 코드를 변경하지 않고 그대로 결과에 출력합니다. 문법을 파싱하는 언어별 도구와 테스트가 준비되기 전까지 결과가 실제로 압축·정렬된다고 가정하지 마세요. 원본 코드는 별도로 보관하세요.

## 파일 구성

- `code.html` — 앱의 HTML 진입 파일
- `styles.css` — 화면 스타일
- `script.js` — 언어 감지, 결과 표시, 복사 동작

## 실행 방법

1. 저장소를 다운로드하거나 클론합니다.
2. 세 파일을 같은 폴더에 둡니다.
3. `code.html`을 브라우저에서 엽니다. `./styles.css`와 `./script.js`를 자동으로 불러옵니다.

저장소에 `index.html`은 없으므로 로컬 실행 시 `code.html`을 여세요.

## 언어 감지

HTML, CSS, JavaScript, Python, C, C++, Go의 간단한 패턴을 감지해 표시합니다. 자동 감지는 완전한 파서가 아니며, 혼합되거나 모호한 코드는 잘못 판별될 수 있습니다. 언어 표시만을 위한 기능이며, 현재 변환 결과에는 영향을 주지 않습니다.

## 향후 최적화/정렬을 다시 활성화하기 전 확인 사항

각 언어에 적합한 파서 기반 변환기를 사용하고, 문자열·주석·템플릿 리터럴·정규식·유니코드·공백 보존 구문을 포함한 테스트를 마련해야 합니다. 변환 결과는 원본과 비교하고 언어별 문법 검사 및 동작 테스트를 통과시킨 뒤에 사용하세요.
