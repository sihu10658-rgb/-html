# 스마트 코드 최적화 도구

브라우저에서 코드를 입력하고 언어를 선택하거나 자동 감지할 수 있는 정적 웹 앱입니다.

## 현재 지원 범위

- **정렬:** Prettier 파서 기반으로 HTML, CSS, JavaScript를 정렬합니다.
- **실제 압축:** Terser 파서 기반으로 JavaScript를 압축합니다. 우선 동작 변경 위험을 낮추기 위해 코드 압축(compress)과 이름 변경(mangle)은 끄고, 불필요한 공백과 일반 주석을 줄입니다. 일부 권리 표시 주석은 보존합니다.
- Python, C, C++, Go 정렬과 HTML/CSS 압축은 아직 지원하지 않습니다. 해당 언어를 선택하면 입력 원문은 그대로 두고 안내 메시지를 표시합니다.
- 자동 언어 감지는 간단한 패턴에 기반하므로 모호하거나 여러 언어가 섞인 코드는 언어를 직접 선택하세요.

> **주의:** 파서 기반 도구도 버그가 전혀 없다고 보장할 수 없습니다. AI 생성 코드와 중요한 코드는 원본을 보관하고, 결과를 비교한 뒤 해당 언어의 문법 검사와 테스트를 통과시켜 사용하세요. 이 앱은 코드를 실행하지 않습니다.

## 파일 구성 및 실행

- `code.html` — 앱 진입 파일
- `styles.css` — 화면 스타일
- `script.js` — 언어 감지와 동작

파일 세 개를 같은 폴더에 두고 `code.html`을 엽니다. 정렬/압축 라이브러리는 `code.html`에서 고정 버전 CDN으로 로드하므로 **해당 기능을 쓰려면 인터넷 연결이 필요합니다**. CDN 로드 실패 시 변환을 적용하지 않고 오류 안내를 표시합니다. 현재는 `index.html`이 없으므로 `code.html`을 여세요.

## 확인 권장

JavaScript 정렬/압축 전후에 Console 오류가 없는지 확인하고, 결과를 원본과 비교하세요. 앱은 변환 결과를 실행하거나 안전성 인증을 하지 않습니다.
