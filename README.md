# 스마트 코드 최적화 도구

브라우저에서 코드를 입력해 언어를 선택하거나 자동 감지하고, 간단한 정렬·최적화를 시험해 볼 수 있는 정적 웹 앱입니다.

> **주의:** 이 도구의 감지·정렬·최적화 기능은 전체 언어 문법을 파싱하지 않습니다. 특히 AI가 생성한 코드나 실제 서비스에 사용할 코드는 결과를 원본 대신 바로 사용하지 마세요. 원본을 보관하고 결과를 직접 비교한 뒤, 해당 언어의 검사기와 테스트로 검증하세요. 문자열·주석·공백이 의도치 않게 바뀔 수 있습니다.

## 파일 구성

- `code.html` — 앱의 HTML 진입 파일
- `styles.css` — 화면 스타일
- `script.js` — 언어 감지, 최적화, 정렬, 복사 동작

## 실행 방법

1. 저장소를 다운로드하거나 클론합니다.
2. `code.html`을 브라우저에서 엽니다.
3. HTML이 `./styles.css`와 `./script.js`를 불러옵니다. 파일 세 개를 같은 폴더에 둡니다.

`index.html`이 아니라 **`code.html`**을 여세요. 저장소에 `index.html`이 없으므로 GitHub Pages의 기본 진입 페이지로 쓰려면 Pages 설정이나 파일명을 별도로 맞춰야 합니다.

## 지원 언어 및 한계

언어 메뉴에는 HTML, CSS, JavaScript, Python, C, C++, Go가 있습니다. 자동 감지는 간단한 패턴에 기반하므로 혼합 코드나 짧고 모호한 코드는 잘못 판별될 수 있습니다. 이 경우 언어를 직접 선택하세요.

현재 구현은 일부 언어에서만 간단한 문자열 기반 처리를 수행합니다. Python, C, C++, Go는 코드 손상을 피하기 위해 최적화 시 원문을 유지합니다. 정렬 기능 역시 언어 파서 기반 포매터가 아니므로 모든 유효한 코드를 보존한다고 보장하지 않습니다. 결과를 빌드·실행·테스트하기 전에는 배포하거나 중요한 코드에 적용하지 마세요.

## 변경 시 확인할 점

- `code.html`에서 `./styles.css`, `./script.js` 경로가 올바른지 확인합니다.
- 앱을 열어 브라우저 개발자 도구의 Console에서 오류가 없는지 확인합니다.
- 각 언어의 대표 코드, 문자열·주석·템플릿 리터럴, 비ASCII 문자를 포함한 테스트를 수행합니다.
- 원본과 결과를 비교하고 언어별 문법 검사 및 자동 테스트를 통과시킵니다.

## 기술

HTML, CSS, 일반 JavaScript를 사용하며 외부 라이브러리나 빌드 도구가 필요하지 않습니다. 스크립트는 ES 모듈이 아닌 일반 스크립트로 연결되어 있습니다.
