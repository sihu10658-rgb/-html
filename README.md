# -html
# ⚡ Smart Code Optimizer (스마트 코드 최적화 도구)

> **OS 제약 없이 브라우저에서 바로 실행되는 웹 기반 코드 최적화/정렬 도구**

별도의 설치나 로컬 서버 설정(`Live Server`, `Node.js` 등) 없이 `index.html` 파일 더블클릭만으로 즉시 구동되는 웹 애플리케이션입니다.

---

##주요 기능

* **자동 언어 감지:** 입력된 코드를 분석하여 HTML, CSS, JS, Python, C++ 자동 식별
* **수동 언어 지정:** 자동 감지 외에 원하는 언어로 직관적 지정 지원
* **코드 압축 (Minify):** 불필요한 공백, 주석, 줄바꿈을 제거하여 파일 용량 최소화
* **코드 정렬 (Pretty Print):** 들여쓰기와 구조를 정돈하여 가독성 확보
* **실시간 용량 계산:** 바이트(Byte) 단위 용량 계산 및 압축 절감률(%) 즉시 측정
* **클립보드 복사:** 원클릭으로 결과물 복사

---

##기술 구조 비교

| 구분 | 일반적인 웹 앱 방식 | 본 프로젝트 방식 |
|---|---|---|
| **실행 방식** | 로컬 서버 필요 (`http://`) | 파일 직접 실행 (`file://`) |
| **CORS 보안** | ES6 Module 제약으로 에러 발생 가능 | 단일/전역 스크립트화로 CORS 에러 0개 |
| **의존성** | npm, Webpack 등 빌드 도구 필요 | Pure HTML5 / CSS3 / Vanilla JS |
| **호환성** | 일부 환경 제약 | Windows, macOS, Linux, 모바일 전체 지원 |

---

##사용 방법

**1. 로컬 환경에서 바로 사용하기**
1. 이 리포지토리를 다운로드(Zip)하거나 클론합니다.
2. `index.html` 파일을 더블클릭하여 브라우저에서 바로 사용합니다.

**2. GitHub Pages 웹 서비스로 활용하기**
* 리포지토리의 `Settings` > `Pages` 메뉴에서 `main` 브랜치를 지정하면 즉시 무료 웹 서비스로 배포됩니다.
